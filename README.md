# LibreELEC PR #106 test build

Experimental GitHub Actions build of [CroqueMr LibreELEC PR #106](https://github.com/CroqueMr/libreelec-x86-DV/pull/106) for Generic x86_64 (AMD Ryzen 7 5800H test target).

Once the workflow is added, run it from the **Actions** tab. A successful run uploads a ZIP artifact containing the LibreELEC update `.tar` and SHA256 checksum. This is **not** a tested image. Check compatibility and back up your LibreELEC installation before applying.
